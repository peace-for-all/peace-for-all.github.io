EARNED(1) · case file · active development

Earned

A personal Android tool exploring how progress can feel visible without becoming surveillance or a game one has to serve.

shape
native Android · local-first state
priority
calm feedback over engagement

rules

A deliberate entry can acknowledge effort. Choices stay reversible, states stay legible, and the path from action to reflection stays short.

work noticed → person records it → restrained reflection
no account · no leaderboard · no social comparison

anti-rules

No punishment for pauses. No assumption that unlike tasks are interchangeable. No streak preserved merely because loss aversion keeps a person returning.

[trace 3/4] inspect minimum viable win

“I showed up” counts as a win; some requirements improve by becoming kinder.

local-state

The core daily flow and local data model are usable in development. Personal data does not need an account or remote audience to provide feedback.

working-model

Useful routines often have delayed rewards, yet measuring them can distort what measurement was meant to support. The current model uses a small number of states and deliberately quiet feedback.

open-questions

Language, rhythm, and the boundary between acknowledgment and pressure remain under test. This is not presented as a validated behaviour-change method. There is no public build or repository yet.
