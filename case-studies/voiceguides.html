VoiceGuides

A native Android app that turns a folder of long guides into listening that can survive a walk, an interruption, and a useful question.

stack
Kotlin · Jetpack Compose · Room · system TTS
contract
local ownership · read-only sources · useful offline

inputs

.md, .markdown, and .txt files arrive through Android’s system folder picker or explicit open/share actions. Markdown is parsed into meaningful listening blocks instead of spoken as punctuation.

state

Room keeps listening position, settings, notes, exploration briefs, and completion reviews on the device. Progress belongs to each guide. JSON backup and restore are deliberate user actions.

source folder → parsed blocks → playback position
passage → anchored note → draft | ready | shared | answered

permissions

The app requests neither internet nor microphone permission. Source folders are scanned read-only. Private offline copies allow chosen material to remain available when the original location is not.

[trace 1/4] inspect permission boundary

No microphone permission; keyboard dictation still works because the keyboard has its own job.

continuity

Playback resumes the right passage and remains controllable through notification, lock screen, and headset controls. Notes stay anchored to the passage that prompted them. Opening the Android share sheet does not silently mark a question as sent.

failure-modes

Speech quality and language support depend on the installed TTS engine. Folder permission can be revoked. An exported backup must be saved and protected by the user. The app reads source folders; it does not edit them.

status

Working pre-release, not a store claim. Public download and source links wait for release, licensing, repository-history, and privacy review.
